# EVEDEX

Hybrid decentralized perpetual-futures exchange on Arbitrum (Layer 3) combining an off-chain order book with on-chain settlement and self-custody. Offers a public developer program with REST APIs (Auth, Exchange, Market Data), WebSocket streaming via Centrifugo, an official TypeScript SDK, and machine-readable OpenAPI specs.

## APIs

- **Auth Service** — User registration and authorization (SIWE/EIP-4361 nonce and sign-up, JWT issuance). (`https://auth.evedex.com/`)
- **Exchange Service** — Core trading API: markets, instruments, orders (limit/market/stop-limit), positions, transfers, and withdrawals. (`https://swagger.evedex.com/`)
- **Market Data Service** — Public historical price data (no authentication required). (`https://market-data-api.evedex.com/`)
